# Third-party notices

artyfact is licensed under AGPL-3.0-only. This file records components that are not covered by that licence or need a note. It is not a full dependency inventory; npm dependencies keep their own licences in `node_modules`.

## elkjs

Used by the Map and Journeys views for graph layout (`apps/platform`, dependency `elkjs`). elkjs is offered under `EPL-2.0 OR GPL-3.0-or-later`. This project uses it under its GPL-3.0-or-later option. GPL-3.0 and AGPL-3.0 are compatible: section 13 of each licence allows combining the two works, and the combined work as a whole stays under AGPL-3.0. artyfact does not modify elkjs. The EPL-2.0 text is kept in `licenses/elkjs-LICENSE.md` because that is the text elkjs ships, and the upstream source is at https://github.com/kieler/elkjs.

## Other dependencies

Checked against the installed tree. Almost every package is MIT, ISC, BSD, Apache-2.0, 0BSD, CC0 or BlueOak, all compatible with AGPL-3.0. Three groups need a note, and none of them is linked into the shipped Worker or SPA code path as a modification.

- `axe-core`, `@axe-core/playwright` and `lightningcss` (MPL-2.0). Test and build tools. MPL-2.0 names the AGPL as a permitted secondary licence, so it is compatible.
- `@img/sharp-libvips` (LGPL-3.0-or-later). An optional native binary pulled in by build tooling. LGPL-3.0 is compatible with AGPL-3.0.
- `apps/platform/worker/env.d.ts` is generated by Wrangler. It carries Cloudflare's Apache-2.0 notices, which stay in the file.

No dependency was found that is incompatible with AGPL-3.0. Run a licence scanner before a release, because this check read `package.json` fields only.

## Brilon (display font)

Not shipped. An earlier version of the theme loaded a Brilon woff2 file, but its licence was never confirmed, so the file and its `@font-face` rule were removed. The display face is Georgia. If the licence is confirmed later, restoring the font is a single revert.
