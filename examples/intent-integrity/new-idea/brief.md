# Neighbourhood tool library

## purpose

Let neighbours publish tools they are willing to lend and request an available
tool for a limited return date.

## boundaries

This is a source-free System draft. It does not process payments, guarantee a
tool's condition, arrange delivery, or create a social feed.

## open-questions

Can one request reserve a tool for multiple neighbours at once? The author has
not decided; the draft must preserve this question rather than infer a rule.
