# Clean tool library control

## purpose

Let a neighbour request one listed tool from one owner and record an agreed
return date.

## boundaries

The System does not process payments, arrange delivery, publish a feed, or
reveal a borrower's contact details to another neighbour.

## acceptance

Given an available tool, when one neighbour sends one request with a return
date, then the owner can accept or decline that request and the request records
that decision.
