# pnpm migration — 2026-10-15

Moved the monorepo from npm to pnpm ([issue #93](https://github.com/sdawka/artyfact-cf/issues/93)): around twenty agent worktrees each carried a full `node_modules`, and the disk filled. pnpm installs from one content-addressed store and hardlinks files into each worktree. Context: [[../execution]].

- **Layout.** `packageManager` pins `pnpm@11.12.0`; `pnpm-workspace.yaml` mirrors the former npm workspace globs and allows the esbuild and workerd install scripts; `pnpm-lock.yaml` came from `pnpm import` of the npm lockfile, which is deleted. Strict linking (no `node-linker=hoisted`): Vite, the Cloudflare plugin, Wrangler, Playwright and workerd all run on symlinked dependencies.
- **Fixes the strict layout forced.** Inter-workspace dependencies use `workspace:*` (the registry now hosts a public `artyfact`, so `*` would have fetched it). `@artyfact/ontology` declares the `@types/node` it was borrowing from hoisting. The CLI bundle resolves bundled licenses from each input's own `node_modules/<name>/` segment. The CLI is a root devDependency so `pnpm exec artyfact` and `scripts/bootstrap.sh` work from the root. `artyfact release` builds with `pnpm --filter` and loads Wrangler from `apps/platform/node_modules`; the operator installs with `pnpm install --frozen-lockfile`.
- **Commands.** Root scripts, `scripts/ci.mjs`, the pre-push hook, the workflow (`pnpm/action-setup`, `cache: pnpm`, frozen install), Playwright web servers (`pnpm exec`), the self-Genome hooks (`pnpm --filter <thing> test`) and the docs now use pnpm. End-user commands stay `npx artyfact@latest`; the app CI sandbox and task packets still run user apps with npm.
- **Evidence.** Fresh worktree `pnpm install --frozen-lockfile` from the shared store: 4.3 s. Locally: typecheck, 282 unit files (3287 tests), platform and site builds, site build test, CLI bundle and pack (a standalone tarball with `workspace:` rewritten), one fixture and one fake e2e spec. Hosted CI is the merge proof.
