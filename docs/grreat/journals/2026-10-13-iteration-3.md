# 2026-10-13 — Iteration 3: ontology engine core

Links: [[../execution]], [[../analysis]], [[../roadmap]].

Iteration 3 landed on branch `iteration-3` as PR #47 (98 commits); local CI is green.

- **Engine:** the bropilot ontology engine was copied into `packages/ontology` and is now the core.
- **Genome v2:** a containment tree with a `node.yaml` per directory plus node-attached files and criteria. v1 is dropped except `artyfact convert-genome --source-map` and a legacy notice.
- **Model:** `packages/model` is a projection (`loadGenome`, `fromGraph`, `composeTemplates`) with strict pinned packs.
- **Gates:** engine evaluate plus `checks@1` on changed nodes, through one System One provider factory (TypeSafe, OpenRouter or fake).
- **Intents:** API and a "Describe a change" panel. Flow: route, translate, validateOps, Proposal, accept with a conditional claim/lease token, genome commit. A node-attached source map drives task packets.
- **UI and templates:** generic UI from a server-serialized views map; generic templates `dev-platform.cloudflare`, `cloudflare-worker-service`, `ts-library`, `cli`, `static-site`.
- **Self-Genome:** repo-root `genome/` with 10 Things and 60 endpoints; `FAKE_SEED=artyfact`. E2E covers intents, the self-model and a ten-view sweep.

Known limits: one webapp Thing per System, Map bands run left to right, and a lapsed-lease takeover can double-push (accepted).

Next: merge on green CI, deploy, migrate the production Keep in Touch Genome to v2 per `docs/deploy.md`, verify live. No hosted or production verification is claimed.
